# BIT hub

App Android (tablet) do BIT, o robô de mesa. É uma "casca" em tela cheia que abre o hub servido pelo robô no PC
(via Tailscale, só aparelhos da conta). O robô 3D, o painel e os balões são os mesmos arquivos do PC.

APK: aba **Releases** → `bit-hub.apk`. Cada push na `main` gera uma versão nova (assinada com a mesma chave, instala por cima).
